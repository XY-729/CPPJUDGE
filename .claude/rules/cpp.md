# CPPJUDGE C++ Rules

- 使用 C++17。
- 不使用 `system()` 执行编译器或用户程序。
- 外部参数不经过 shell 字符串拼接。
- fork 后必须正确处理 exec 失败。
- 必须关闭不需要的文件描述符。
- 必须回收子进程。
- runner 修改必须检查进程组清理。
- 资源限制修改必须检查单位和溢出。
- 内存逻辑修改必须运行 MLE 与普通 RE 回归。
- 公共结果类型修改必须检查 compiler、runner、judge 和日志调用方。
- 不进行无关全文件格式化。
- 不用大范围重写代替局部修复。
